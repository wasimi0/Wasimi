# Hatoyoke

鳥を避けながら30秒間生き残る、Windows向けの2D回避ゲームです。前方へ発射するスキルで小さな鳥を一時的に消し、進路を確保します。大きな鳥にはスキルが効かないため、移動で避ける必要があります。

## 起動方法・操作

ZIPをすべて展開し、`Game`内の`Hatoyoke.exe`を起動します。`engine`・`dll`・`example`フォルダーはexeと同じ場所に保ってください。

操作説明の「難易度選択へ」からゲームを開始します。難易度選択画面から説明へ戻ることもできます。

| 操作 | 内容 |
|---|---|
| WASD / 矢印キー | 移動 |
| Eキー | 前方へスキルを発射 |
| マウス左クリック | ボタン選択 |

- 鳥に触れずに30秒間生き残るとクリアです。
- スキルは開始直後から使用でき、再使用まで10秒かかります。使用可能時はREADYと表示します。
- 弾は貫通し、小さな鳥を5秒間消します。大きな鳥は消えず、弾が通り抜けます。
- どちらの鳥も、プレイヤーが触れるとゲームオーバーです。
- 結果画面のRetryで難易度選択に戻ります。

| 難易度 | 小さな鳥 | 大きな鳥 | 基準速度に対する倍率 |
|---|---:|---:|---:|
| EASY | 6体 | 0体 | 0.7倍 |
| NORMAL | 6体 | 1体 | 1.0倍 |
| HARD | 6体 | 2体 | 1.1倍 |

## 実装と工夫

### 画面の状態管理

`GameState`で操作説明・難易度選択・プレイ・ゲームオーバー・クリアを区別しています。ゲームの開始・終了・リトライを関数に分け、再開時に弾とタイマーを初期化します。結果画面では時間を停止し、生存時間やクリアした難易度を表示します。

### スキルと敵の状態管理

スキルのクールタイムと、敵の復帰までの時間を別々に管理しています。弾は命中済みの敵を記録します。大きな鳥にはスキル耐性を設定し、弾の対象から除外する一方、プレイヤーとの接触判定は残しています。

### 表示と判定の整合性

移動量に経過時間を反映し、敵を移動してから弾との衝突判定を行います。弾の矩形判定は画像サイズに合わせています。白背景は矩形の判定範囲を把握しやすくするため、意図して残しています。説明・難易度選択・結果表示には黒い半透明の背景を使用しています。

入力、描画、矩形の交差判定にはSiv3Dの機能を使用しています。

## ビルド方法

1. Visual Studio 2022の「C++によるデスクトップ開発」、v143ツールセット、Windows SDKを用意します。
2. OpenSiv3D 0.6.16を導入し、環境変数`SIV3D_0_6_16`にSDKの配置先を設定します。変更後はVisual Studioを再起動してください。
3. `Source/sunaipu 2026 0126.sln`を開きます。
4. `Release / x64`でビルドします。
5. 生成された`Source/sunaipu 2026 0126/App/sunaipu 2026 0126.exe`を起動します。

SDKは同梱していません。完成済みの`Game/Hatoyoke.exe`を遊ぶ場合、Visual Studioでのビルドは不要です。
